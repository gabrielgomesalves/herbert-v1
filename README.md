## ⚠️ Read this first — a time capsule

Herbert was written **a long time ago (2015–2016), by hand, before the "AI era"** — no Copilot, no ChatGPT, just
documentation, Stack Overflow and stubbornness. It ran for years on a **private studio LAN**, used daily by
engineers and voice actors, and it did its job well.

That context matters, because it was **never designed to face the internet**. It has several well-known problems
(listed honestly in [Known problems](#-known-problems)) that were acceptable on a trusted LAN and are **not**
acceptable anywhere else. It's published here as-is for archaeology, learning, and nostalgia — and as a decent
starting point if you want to rebuild the idea properly.

> **Do not expose this application to the public internet.**

## ✨ What it does

Herbert manages the day-to-day paperwork of a dubbing (voice-over) studio, so the recording booth runs smoothly:

| Area                        | What you can do                                                                                                                                                                                                             |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 📥 **Script import**        | Drag & drop Excel (`.xls`/`.xlsx`) scripts. Series, episodes, characters (with gender) and every line with its **timecode** are parsed and stored in a single transaction. Failed rows are reported with their line number. |
| 📖 **Script viewer**        | Read an episode's script in the booth, mark takes as *done*, edit speech inline (rich-text editor), search & highlight words, jump top/middle/bottom on a phone or tablet.                                                  |
| 🎭 **Casting**              | Assign actors to characters per series — manually or with the **casting automaton** that distributes roles in bulk.                                                                                                         |
| ⚔️ **Conflict detection**    | Spots characters that overlap in the same take so one actor isn't cast in two simultaneous roles, and lets you swap characters.                                                                                             |
| 🧑‍🎤 **Actors**             | Directory with contact info, notes, and a **printable history** (PDF) of every series/episode/character they voiced.                                                                                                        |
| 📺 **Series & episodes**    | Track state (open / done), print episode sheets to PDF with the studio logo.                                                                                                                                                |
| ✍️ **Corrections**           | Log director's notes per series / episode / timecode / actor, and tick them off when fixed.                                                                                                                                 |
| 📚 **Glossary**             | Per-series pronunciation guide for names and tricky words.                                                                                                                                                                  |
| 🎵 **Songs**                | Lyrics and timecodes for musical numbers.                                                                                                                                                                                   |
| 📊 **Statistics & exports** | Per-series Excel statistics (words and takes per character/actor/episode) and ZIP packages of a series' scripts, generated by artisan commands.                                                                             |

The UI is a **jQuery Mobile** single-page-ish layout, so it works on a tablet next to the mic as comfortably as on a desktop.
Interface language: **European Portuguese** (strings are hard-coded in the views).

## 🧱 Stack

- **Backend:** PHP + [Laravel 5.1 (LTS)](https://laravel.com/docs/5.1), MySQL
- **Libraries:** `maatwebsite/excel` (import/export), `barryvdh/laravel-dompdf` (PDFs), `chumper/zipper` (ZIPs),
  `spatie/laravel-backup`, `laravelcollective/html`, Carbon
- **Frontend:** jQuery, jQuery Mobile 1.4, Dropzone, Trumbowyg, qTip, toastr, jquery-confirm, mark.js, Font Awesome
  (vendored under `public/scripts/`)

```
app/
├── Console/Commands/    # create:serie_statistics · create:serie_zip · clear:file_folder
├── Http/Controllers/    # Script · Serie · Episode · Actor · Character · Assignment · Correction · Glossary · Song
├── *.php                # Eloquent models (Serie, Episode, Script, Character, Actor, Assignment, ...)
database/migrations/     # schema (+ a MySQL `wordcount()` function used by the statistics)
resources/views/         # Blade + jQuery Mobile pages, PDF templates
public/scripts/          # third-party JS/CSS, vendored
```

## 🚀 Getting it running

You'll need an **old PHP** (Laravel 5.1 supports PHP 5.5.9 up to roughly 7.x; use Docker/a VM, not your main machine's PHP),
**Composer**, and **MySQL/MariaDB**.

```bash
git clone <this-repo> herbert && cd herbert
composer install                 # restore vendor/ (it is not committed)

cp .env.example .env             # then edit DB_* credentials
php artisan key:generate

mysql -e "CREATE DATABASE herbert CHARACTER SET utf8 COLLATE utf8_unicode_ci"
php artisan migrate              # creates tables AND the wordcount() MySQL function

php artisan serve                # → http://localhost:8000
```

Make sure `storage/` and `bootstrap/cache/` are writable, and that `public/files/` exists
(generated statistics and ZIPs are written there).

### Script file format

Each uploaded workbook is expected to contain these sheets:

- **`info geral`** — column B, rows 1–5: original series name, original episode name, translated series name,
  translated episode name, episode number.
- **`texto`** — one line per take: column A timecode, column B `CHARACTER (gender)`, column C speech.
- **`cancoes`** — songs: column A timecode, column B song name, column C lyrics.

### Branding

PDFs use `public/img/company_logo.png`. A neutral placeholder ships with the repo — replace it with your own logo.

## 🩹 Known problems

Honest list, so nobody has to find them the hard way:

- 🔓 **No authentication or authorization.** Laravel's auth scaffolding is present but no route is protected.
  Anyone who can reach the server can read, edit and delete everything. (This was the LAN trust model.)
- 💉 **SQL built by string interpolation** in several controllers/commands (`'$serie_id'`, `'$actor_id'`) — injectable.
- 📤 **Weak upload handling:** the client-supplied filename is used as-is and there's no strict type validation.
- 🌍 **Generated exports land in `public/files/`**, i.e. directly web-accessible.
- 🧓 **End-of-life stack:** Laravel 5.1 and PHP 5.x/7.x no longer receive security fixes; several dependencies are abandoned.
- 🧪 **Basically no tests** (only the framework's example test).
- 🍝 **Fat controllers**, heavily duplicated queries, no form requests, little validation, inline JS in Blade views.
- 🌐 **Hard-coded Portuguese UI**, no i18n.
- 🐛 `APP_DEBUG` was left on in the original deployment — don't copy that; `.env.example` now defaults it to `false`.

If you're thinking "I could fix this": please do — see below.

## 🧹 About this repository

This public version was **sanitised** before publishing: credentials and app keys removed (and no longer hard-coded
as config fallbacks), production logs, sessions and caches dropped, the original studio logo replaced by a
placeholder, bundled demo files trimmed, and `vendor/` left out in favour of `composer install`.

If you ever deploy a fork, **generate a fresh `APP_KEY` and use your own database credentials** — never reuse anything
from a template.
